## ✨ Features

| Feature | Description |
|---------|-------------|
| **Responsive Design** | Fully optimized for desktop, tablet, and mobile devices |

## 🚀 Getting Started

No build tools or package installation required — just clone and open!

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, Safari)
- Internet connection (for CDN-loaded fonts, icons, and animations)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/Rednarock016/Portfolio-website.git
   cd Portfolio-website
   ```

2. **Open in browser**

   Simply open `index.html` directly, or start a local server:

   ```bash
   # Using Python
   python -m http.server 8080

   # Using Node.js
   npx serve .

   # Using VS Code
   # Install "Live Server" extension → Right-click index.html → "Open with Live Server"
   ```

3. **Visit** → [http://localhost:8080](http://localhost:8080)

## 🎨 Customization

Want to use this as a template? Here's what to modify:

| What to Change | Where |
|----------------|-------|
| Personal info & text | `index.html` — update name, bio, about section |
| Social links | `index.html` — search for `href` in social buttons |
| Profile photo | Replace `assets/Profile pic.png` |
| Resume PDF | Replace `assets/Ranjit-Hazra-ATS.pdf` |
| Projects | `index.html` — edit the `#project` section cards |
| Colors & theme | `style.css` — modify CSS custom properties |
| Contact form | `index.html` — update the Formspree action URL |
| Analytics | `script.js` — replace `G-XXXXXXXXXX` with your GA4 ID |

## 🌐 Deployment

This site is deployed on **GitHub Pages**. To deploy your own:

1. Push the code to a GitHub repository
2. Go to **Settings** → **Pages**
3. Set source to the `main` branch
4. Your site will be live at `https://rednarock016.github.io/Portfolio-website/`
